## ไฟล์ในโปรเจกต์
- `index.html`: ไฟล์หน้าเว็บหลัก (รองรับการเปิดใช้งานบน GitHub Pages ทันที)
- `landing-page.html`: ไฟล์ต้นฉบับสำรอง

## วิธีเปิดใช้งาน
สามารถเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ได้โดยตรง หรือเปิดผ่าน Live Server
